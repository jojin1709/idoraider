# Security Policy

## Supported Versions

Only the latest release on the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in IDORaider, please report it responsibly:

1. **Do not disclose the issue publicly** on public issues or forums.
2. Please submit a private vulnerability advisory via [GitHub Security Advisories](https://github.com/jojin1709/idoraider/security/advisories) or contact the project maintainer [JOJIN JOHN](https://github.com/jojin1709).
3. Include:
   - Description of the vulnerability.
   - Proof of concept or reproduction steps.
   - Potential impact.

We take security issues seriously and will review and address reports promptly.
